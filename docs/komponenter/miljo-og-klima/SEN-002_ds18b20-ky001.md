# DS18B20 digital temperatursensor (KY-001)

![DS18B20 digital temperatursensor (KY-001)](/bilder/komponenter/SEN-002.jpg)


| Nøkkelfakta | Verdi |
| :--- | :--- |
| **Lokasjon** | Uavklart |
| **Signaltype** | Digital 1-Wire |
| **Driftsspenning** | Må bekreftes for modulen |
| **Signalspenning** | Bestemmes av pull-up-kretsen; må kontrolleres |
| **Bibliotek** | `OneWire`, `DallasTemperature` |

## 1. Beskrivelse
DS18B20 måler temperatur og kommuniserer digitalt over 1-Wire. Inventarnotatet identifiserer modulen som KY-001, men det må kontrolleres om den har innebygd pull-up-motstand.

## 2. Tilkobling (Pinout)
| Pinne på modul | Navn | Kobles til ESP32 / Arduino | Merknad |
| :--- | :--- | :--- | :--- |
| **S** | 1-Wire data | GPIO 4 som eksempel | Kontroller pinneetikett og pull-up-krets. |
| **+** | Forsyning | Må bekreftes | Ikke anta at 5 V er trygt for datasignalet. |
| **-** | Jord | GND | Felles jord. |

> **Viktig sikkerhetsvarsel:** ESP32 GPIO tåler ikke 5 V. Dersom datalinjen trekkes opp til 5 V, kan det skade kortet. Bruk bare en bekreftet 3,3 V pull-up med ESP32.

## 3. Kodeeksempel (C++ PlatformIO / Arduino IDE)
Eksemplet forutsetter at modulens pinout og 1-Wire-spenning er kontrollert.

```cpp
#include <Arduino.h>
#include <OneWire.h>
#include <DallasTemperature.h>

OneWire oneWire(4);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(115200);
  sensors.begin();
}

void loop() {
  sensors.requestTemperatures();
  Serial.println(sensors.getTempCByIndex(0));
  delay(1000);
}
```

## 4. Feilsøking (Typiske elevfeil)
* **Ingen sensor finnes:** Kontroller dataforbindelse, felles jord og eventuell pull-up.
* **ESP32 får 5 V på data:** Koble fra; kontroller pull-up-spenningen før ny test.
* **Ustabil måling:** Kontroller ledninger og at kodebibliotekene er installert.
